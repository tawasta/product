=======================================
Sales of last year in product list view
=======================================

Shows all the sales made in the list view of products.
A user can hide this field from tree view options.

Configuration
=============
No configuration is necessary

Usage
=====
Go to Apps and install the module

Known issues / Roadmap
======================
Since this module only adds a field to tree view, it will not
create issues for other modules.
