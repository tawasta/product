=====================================
Product Materials on Product template
=====================================

::

    Enable to set materials also on product templates.

    This is meant to be merges later with product_materials module,
    but this merge needs to checked that already created materials
    on variants will not be affected by this change.

Configuration
=============
::

    Set materials the same way as is done in product variants.

Usage
=====
::

    Select a product and create materials for it. Admin user can also
    update product template information on previously created materials
    if needed.

Known issues / Roadmap
======================
::

    Consider merging this module with product_materials.
