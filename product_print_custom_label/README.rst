===================================================
Print custom product label for pallets and boxes
===================================================
Adds a new report for printing a landscape A4 label for products. 
Label contains product name, quantity, code, barcode, default location and date. 
Code and quantity is printed in large font for easy scanning and reading 
from a distance.

Configuration
=============
Install the module

Usage
=====
Go to any product form view and click on the "Print labels" button. 
Then select the A4 Custom label and input product and pallet quantities.
