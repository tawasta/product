===================================================
Adds formula text based on the profile of a product
===================================================

::

    Define the rules of a product profile formula. Then assign the profile
    formula to a product to show the combined results of the measurements
    of a product in one field. The functionality is purely informative.

Configuration
=============
::

    Create a record of product profile formula and set specific rules to it.

Usage
=====
::

    A value can be written to profile_info_type -field of product.product.
    This operation will trigger a search to assign a product profile formula
    to profile_info_id -field.
