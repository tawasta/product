======================================
Change Quantity On Hand to be readonly
======================================

::

    Disable to directly edit Quantity On Hand of a product.

    This modification is meant to be used when a single stock location
    is being used. Because with multiple locations enabled editing
    quantity on hand directly is done with opening stock quant list
    from a product. This is not prevented by this module.

Configuration
=============
::

    A single internal stock location is meant to be used.

Usage
=====
::

    Go to a product and see how modifying quantity on hand directly is
    prevented in product form view

Known issues / Roadmap
======================
