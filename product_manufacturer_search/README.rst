========================================
Search products with manufacturer fields
========================================

* Search products with manufacturer fields: Manufacturer, Manufacturer Product
  Name and Manufacturer Product Code

Configuration
=============
\-

Usage
=====
* Type in the product search and choose one of the manufacturer options

Known issues / Roadmap
======================
* Products with several variants have no manufacturer values on the product
  itself, so they are not found by these searches
