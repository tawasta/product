=======================
Product Item Code Label
=======================
This module adds a new field **Item Code** to products and prints it on
various product label formats.

**Supported label templates:**
* 2x7
* 4x7
* 4x12
* 4x12 (no price)

Configuration
=============
No configuration is needed. Install the module and start using the new field.

Usage
=====
1. Open a product form.
2. Fill in the **Item Code** field.
3. Print product labels — the Item Code will appear below the barcode.
