=================================
Revision Code of product template
=================================

::

    Install the module to have revision_code -field on product.template model.
    The field is shown in its form view and it is purely informative on its own.
    This field is primarily meant to be used together with other functionalities.

Configuration
=============
::

    No configuration is necessary

Usage
=====
::

    Go to Apps to install the module

Known issues / Roadmap
======================
::

    Check if there exists a module in the installation that uses the same
    technical field name, revision_code, on product.template model.
