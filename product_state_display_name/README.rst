=================================================
Product State Display Name
=================================================

Adds a Product Status Name field to products that displays the 
name of the product state. Gets the name from the product_state 
module, but the that module only displays the state code.

Configuration
=============
\-

Usage
=====
- Install the module and the Product Status Name field 
will appear in the product form and list views.
