====================
Product: Fall Height 
====================

* Adds a new field, Fall Height, to products

  * For e.g. playground equipment, defining the greatest height
    from which it is possible to fall.
* Depends on OCA's product_dimensions for UOM management

Configuration
=============
* None needed

Usage
=====
* Go to Product Variant or Template form to see the new field
