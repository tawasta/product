====================================
Show Putaway rules count on products
====================================

::

    Normally Putaway rules smart button is shown without their counted number.
    This module adds that number to the smart button.

Configuration
=============
::

    No configuration is necessary

Usage
=====
::

    Install the module from Apps and see how putaway rules count is added
    to the Putaway rules smart button.

Known issues / Roadmap
======================
::

    The module is purely informative.
