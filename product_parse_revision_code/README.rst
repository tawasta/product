======================================
Parse Revision Code From Default Code
======================================

Intended for setups where the revision code is embedded as the last
word of the product default code, but the revision_code field is
maintained separately on the product template.


Configuration
=============


Usage
=====

* Go to Apps to install the module. The scheduled action "Mass parse
  revision codes from default codes" is created automatically and can
  be run manually from Settings > Technical > Automation > Scheduled
  Actions.
* The scheduled action can be configured to run automatically at a
  desired interval, e.g. once a day. This is done from the same place as above.
