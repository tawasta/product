=====================
Product Tag Sequence
=====================
* Order webstore product tags by sequence
* Used to edit the order of product tags shown in the webstore

Configuration
=============
* Install the module from the Odoo apps menu

Usage
=====
* Reorder product tags by dragging and dropping in product.tag list view
