===========================
Description log from import
===========================

::

    Adds a new field, change_description, which is meant to be used
    when importing data to Odoo. Thus this field is only informative
    and it does not contain any functionalities related to other fields
    or functions.

Configuration
=============
No configuration is required to use this module

Usage
=====
Go to Apps and install the module. Then import data to change_description field.

Known issues / Roadmap
======================
Check if future odoo version have a same change_description field that is
used on product.product model.
