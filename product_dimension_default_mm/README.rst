====================================
Product Dimension Default Millimeter
====================================

This module changes the default value of the **Dimensional UoM** field on
products from **Meter** to **Millimeter**.

The standard product dimension module sets the dimensional unit of measure
to meters for newly created products and variants. This customization
overrides the default and uses millimeters instead.

Configuration
=============
No configuration is required.

Usage
=====
#. Install the module.
#. Create a new product.
#. The **Dimensional UoM** field will automatically default to
   **Millimeter**.

Existing products are not modified.
