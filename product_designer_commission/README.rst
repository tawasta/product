===========================
Product Designer Commission
===========================
This module extends products and contacts to support **designers and their commissions**.

It allows assigning a designer to products and storing commission percentages
for each designer.

**Key features:**

- Add a *Designer* field to products
- Mark contacts as designers
- Store commission percentage on designers
- Filter and group products by designer
- Search and filter designers in contacts


Configuration
=============
1. Go to **Contacts**
2. Open or create a contact
3. Enable:

   - *Is a Designer*
4. Set:

   - *Commission (%)*

Usage
=====
**Assign a designer to a product:**

1. Go to **Products**
2. Open a product
3. Select a designer in the *Designer* field

Only contacts marked as *Is a Designer* are selectable.

**Search and grouping:**

- Filter contacts using *Designers*
- Group products by *Designer* in search view
