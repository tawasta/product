=============================
Product default type: product
=============================

* New goods products track inventory ("Track Inventory" checked) by default,
  also when products are imported or created by integrations
* Services and combos are not tracked in inventory
* In menus that create services by default (e.g. Services), a product changed
  to Goods is not tracked automatically: check "Track Inventory" manually

Configuration
=============
* No configuration needed
